# Implementações dos bancos

Cada integrante desenvolve nesta pasta a modelagem lógica e o módulo Python do banco que lhe foi atribuído. As três implementações usam o mesmo contrato de consultas e resultados.

- [SQLite](sqlite/README.md): banco relacional em arquivo local, sem serviço externo.
- [MongoDB](mongodb/README.md): banco documental.
- [Neo4j](neo4j/README.md): banco de grafos.

Antes da integração com a interface, a equipe deve alinhar o formato compartilhado das consultas e dos resultados.
